# filter_integers

Write a Jac function that takes a dictionary as input and returns a new dictionary with all the key-value pairs where the values are integers. The function should ignore non-integer values.

Example:
- `filter_integers({'a': 'string', 'b': 3.5, 'c': None, 'd': [1, 2]}) == {}`

Implement `filter_integers(d: dict[str, int]) -> dict[str, int]`.
