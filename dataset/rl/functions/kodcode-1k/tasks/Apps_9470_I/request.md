# is_palindrome

=====Problem Statement=====
A palindrome is a word, phrase, number, or other sequences of characters that reads the same forward and backward (ignoring spaces, punctuation, and capitalization). For example, 'madam' and 'nurses run' are palindromes.

Given a string `s`, your task is to determine if it is a palindrome. Ignore cases, spaces, and non-alphanumeric characters. 

Implement the function `is_palindrome(s)` which returns the Boolean value True if `s` is a palindrome, and False otherwise.

=====Input Format=====
A string `s`.

=====Constraints=====
1 ≤ len(s) ≤ 10^5

=====Output Format=====
The function must return a Boolean value (True/False). Output is handled by the provided code stub.

Example:
Input: 'A man, a plan, a canal, Panama'
Output: True

Example:
- `is_palindrome('madam') == True`

Implement `is_palindrome(s: str) -> bool`.
