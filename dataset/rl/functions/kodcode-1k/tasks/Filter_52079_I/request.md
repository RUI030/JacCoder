# sum_of_fibonacci

Write a function in Python that calculates the sum of the first n Fibonacci numbers. The function should be efficient and handle large values of n. Use a method that avoids recalculating Fibonacci numbers, such as dynamic programming or memoization. Provide a brief explanation of your approach.

Example:
- `sum_of_fibonacci(0) == 0`

Implement `sum_of_fibonacci(n: int) -> int`.
