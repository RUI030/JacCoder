# min_merge_cost

Calculate the minimum cost required to merge all the given shipments into a single shipment.

Args:
weights (List[int]): A list of integers representing the weights of the shipments.

Returns:
int: The minimum cost required to merge all the shipments.

Example:
>>> min_merge_cost([4, 3, 2, 6])
29

Implement `min_merge_cost(weights: list[int]) -> int`.
