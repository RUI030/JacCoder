# maxPairProduct

Given an array of integers, find the product of the maximum pair (i.e., two different elements) in the array.

The array will contain at least two integers, and each integer is greater than or equal to 1.

>>> maxPairProduct([3, 5, 2, 6])
30
>>> maxPairProduct([10, 2, 3])
30

Implement `maxPairProduct(arr: list[int]) -> int`.
