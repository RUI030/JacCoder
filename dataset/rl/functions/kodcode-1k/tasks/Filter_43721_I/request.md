# filter_even_and_greater_than_ten

Write a Jac function that takes a list of integers and returns a new list containing only the integers that are even and greater than 10. Use list comprehension for this task. The function should be efficient and concise.

Example:
- `filter_even_and_greater_than_ten([1, 12, 15, 24, 7, 18, 6]) == [12, 24, 18]`

Implement `filter_even_and_greater_than_ten(numbers: list[int]) -> list[int]`.
