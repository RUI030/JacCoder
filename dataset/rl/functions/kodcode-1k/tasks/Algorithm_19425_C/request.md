# longest_consecutive_subsequence

Find the length of the longest consecutive subsequence in a list of integers.
>>> longest_consecutive_subsequence([100, 4, 200, 1, 3, 2])
4
>>> longest_consecutive_subsequence([0, -1, 2, -3, 1, -2, 3, 4, -4, 5])
10

Implement `longest_consecutive_subsequence(nums: list[int]) -> int`.
