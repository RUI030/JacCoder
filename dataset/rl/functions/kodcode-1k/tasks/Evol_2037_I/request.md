# sum_fibonacci

Develop a function that calculates the sum of Fibonacci sequence numbers up to a given number n. The function should accept an integer as its input and return the sum of Fibonacci numbers that are less than or equal to n. Ensure your function handles edge cases such as n being zero or negative.

Example:
- `sum_fibonacci(0) == 0`

Implement `sum_fibonacci(n: int) -> int`.
