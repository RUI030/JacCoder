# merge_sorted_arrays

Merges two sorted arrays into a single sorted array.

Parameters:
    arr1 (list of int): First sorted array.
    arr2 (list of int): Second sorted array.

Returns:
    list of int: Merged and sorted array.

>>> merge_sorted_arrays([1, 3, 5], [2, 4, 6])
[1, 2, 3, 4, 5, 6]
>>> merge_sorted_arrays([0, 2, 4], [1, 5, 7])
[0, 1, 2, 4, 5, 7]

Implement `merge_sorted_arrays(arr1: list[int], arr2: list[int]) -> list[int]`.
