# greater_than_mean

Design a function in Python that takes a list of integers and returns a new list containing only the elements that are greater than the arithmetic mean of the original list. The order of elements in the returned list should be the same as their order in the input list.

Example:
- `greater_than_mean([1, 1, 1, 1]) == []`

Implement `greater_than_mean(lst: list[int]) -> list[int]`.
