# even_integers_sorted

Write a function that takes in a list of integers and returns a new list consisting of only the even integers from the original list, sorted in non-decreasing order. Implement this function without using built-in sort functions.

Example:
- `even_integers_sorted([1, 3, 5, 7]) == []`

Implement `even_integers_sorted(lst: list[int]) -> list[int]`.
