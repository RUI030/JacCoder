# sum_of_unique_abs_pairs

This function takes in a list of integers `nums` and returns the sum of the absolute
values of the unique pairs of integers that add up to zero.

>>> sum_of_unique_abs_pairs([1, -1, 2, -2, 3, 1, -1])
6
>>> sum_of_unique_abs_pairs([3, -3, -3, 3, 2, 2])
6

Implement `sum_of_unique_abs_pairs(nums: list[int]) -> int`.
