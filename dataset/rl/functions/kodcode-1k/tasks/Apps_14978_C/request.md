# contains_nearby_duplicate

Checks whether there are two distinct indices i and j in the array such that nums[i] = nums[j]
and the absolute difference between i and j is at most k.
>>> contains_nearby_duplicate([1, 2, 3, 1], 3) == True
>>> contains_nearby_duplicate([1, 0, 1, 1], 1) == True

Implement `contains_nearby_duplicate(nums: list[int], k: int) -> bool`.
