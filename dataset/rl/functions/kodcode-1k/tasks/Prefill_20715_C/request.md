# int_to_padded_binary

Create a function that takes an integer as input and returns its binary representation as a string.
The binary representation should be zero-padded to a minimum length of 8 bits.

>>> int_to_padded_binary(5) == "00000101"
>>> int_to_padded_binary(0) == "00000000"

Implement `int_to_padded_binary(n: int) -> str`.
