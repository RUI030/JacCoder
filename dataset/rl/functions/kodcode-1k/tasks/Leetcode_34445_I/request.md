# find_single_element

You are given an array of `n` integers where every element appears exactly twice except for one element which appears only once. Write a function to find the element that appears only once. Your solution should have a linear runtime complexity and use only constant extra space.

Example:
- `find_single_element([2, 1, 4, 5, 2, 4, 1]) == 5`

Implement `find_single_element(arr: list[int]) -> int`.
