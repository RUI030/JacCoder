# smallestNumber

Given a string that contains only digits from '0' to '9', find the smallest number that can be formed by removing at most one digit from the given number. If removing a digit is not possible or doesn't lead to a smaller number, return the original number as it is.
>>> smallestNumber("15243") "1243"
>>> smallestNumber("1000") "000"

Implement `smallestNumber(num: str) -> str`.
