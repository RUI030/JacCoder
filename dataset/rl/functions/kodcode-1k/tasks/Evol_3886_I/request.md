# first_non_repeating_char

Design a function in Python that takes a string as input and returns the first non-repeating character in it. If all characters are repeating or the string is empty, return None. Ensure your solution is efficient in time complexity. 

**Example:** 
- Input: "swiss"
- Output: 'w'

- Input: "repetition"
- Output: 'r'

- Input: "aabbcc"
- Output: None

Write the function signature as follows: `def first_non_repeating_char(s: str) -> str:`

Example:
- `first_non_repeating_char('swiss') == 'w'`

Implement `first_non_repeating_char(s: str) -> str | None`.
