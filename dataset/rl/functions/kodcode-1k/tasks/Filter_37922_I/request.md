# find_pairs

Write a Jac function to find all unique pairs of numbers in a list that add up to a given target sum. Remember to consider cases where the list might contain duplicate elements but you should not return duplicate pairs. To add a bit more complexity, you will also need to ignore the element at the index specified by a variable 'ignore_index', if it appears.

Example:
- `find_pairs([1, 2, 3, 2, 3, 4], 5, -1) == [(2, 3), (1, 4)]`

Implement `find_pairs(numbers: list[int], target: int, ignore_index: int) -> list[tuple[int, int]]`.
