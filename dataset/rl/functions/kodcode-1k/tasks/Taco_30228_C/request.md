# count_distinct_special_words

Returns the number of distinct special words that can be formed 
by inverting exactly one lamp state.

>>> count_distinct_special_words(5, [1, 1, 0, 0, 1])
5
>>> count_distinct_special_words(3, [1, 1, 1])
3

Implement `count_distinct_special_words(n: int, lamp_states: list[int]) -> int`.
