# smallest_lexicographical_substring

Given a string s and an integer n, find the lexicographically smallest 
substring of length n. The function returns the smallest substring as per 
alphabetical order. If there are multiple substrings with the same smallest 
lexicographical order, the first one occurring is returned.
>>> smallest_lexicographical_substring("programming", 3) == "amm"
>>> smallest_lexicographical_substring("abc", 1) == "a"

Implement `smallest_lexicographical_substring(s: str, n: int) -> str`.
