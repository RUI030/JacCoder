# two_sum_sorted

Find two numbers in the sorted array `arr` that sum up to `target`.
Return the 1-based indices of these two numbers. If no such indices
exist, return -1, -1.

>>> two_sum_sorted([1, 2, 4, 4, 5], 8)
(3, 4)
>>> two_sum_sorted([1, 2, 3, 4, 5], 10)
(-1, -1)

Implement `two_sum_sorted(arr: list[int], target: int) -> tuple[int, int]`.
