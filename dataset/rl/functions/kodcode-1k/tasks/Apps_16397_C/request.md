# remaining_passengers

Calculate the total number of passengers remaining on the bus after the last stop.
>>> remaining_passengers([(10, 0), (3, 5), (5, 8)]) == 5
>>> remaining_passengers([(3, 0), (9, 1), (4, 10), (12, 2), (6, 1), (7, 10)]) == 17

Implement `remaining_passengers(bus_stops: list[tuple[int, int]]) -> int`.
