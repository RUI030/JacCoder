# three_sum

You are given an integer array `arr` of positive integers and an integer `target`. You need to determine if there are three distinct elements in `arr` that add up to the `target`. If such elements exist, return `true`, otherwise return `false`. Make sure your algorithm runs with a time complexity of O(n^2).

Example:
- `three_sum([1, 2, 3, 4, 5], 9) == True`

Implement `three_sum(arr: list[int], target: int) -> bool`.
