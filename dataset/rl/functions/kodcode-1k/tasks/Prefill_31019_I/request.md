# count_characters

Write a Jac function to count the occurrences of each character in a string and return the result as a dictionary. The function should ignore case sensitivity by converting all characters to lowercase before counting.

Example:
- `count_characters('abc') == {'a': 1, 'b': 1, 'c': 1}`

Implement `count_characters(s: str) -> dict[str, int]`.
