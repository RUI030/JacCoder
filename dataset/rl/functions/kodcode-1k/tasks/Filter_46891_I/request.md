# check_email

Write a Jac script that checks if a given string is a valid email address using regular expressions. The script should take an input string and print 'Valid Email' if the string is a valid email address, and 'Invalid Email' otherwise. Make sure to consider common email formats in your regular expression.

Example:
- `check_email('test.email@example.com') == 'Valid Email'`

Implement `check_email(email: str) -> str`.
