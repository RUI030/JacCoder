# sortedArraySquares

Given a list of integers sorted in non-decreasing order, returns a list of the squares of each number in sorted non-decreasing order.
>>> sortedArraySquares([1, 2, 3, 4]) == [1, 4, 9, 16]
>>> sortedArraySquares([-4, -3, -2, -1]) == [1, 4, 9, 16]

Implement `sortedArraySquares(nums: list[int]) -> list[int]`.
