# can_split_to_two_non_decreasing_subarrays

Determine if it is possible to split the array into exactly two non-empty subarrays
where both subarrays are non-decreasing.

Parameters:
arr (list of int): The array representing the height of buildings.

Returns:
bool: True if such a split is possible; False otherwise.

>>> can_split_to_two_non_decreasing_subarrays([1, 2, 3, 4, 5]) == True
>>> can_split_to_two_non_decreasing_subarrays([5, 4, 3, 2, 1]) == False

Implement `can_split_to_two_non_decreasing_subarrays(arr: list[int]) -> bool`.
