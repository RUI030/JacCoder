# longest_valid_word

Implement a function in Python that finds the longest word in a given string that uses only the first 10 letters of the English alphabet ('a' through 'j'). If there are multiple longest words, return the first one found. If the input string contains letters beyond 'a' to 'j', ignore them.

Example:
- `longest_valid_word('abc zz abcde hello') == 'abcde'`

Implement `longest_valid_word(s: str) -> str`.
