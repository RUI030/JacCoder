# sum_of_digits_of_largest_number

Write a function to find the sum of the digits of the largest number in a list of non-negative integers.
>>> sum_of_digits_of_largest_number([5]) 5
>>> sum_of_digits_of_largest_number([9, 18, 27, 36]) 9

Implement `sum_of_digits_of_largest_number(numbers: list[int]) -> int`.
