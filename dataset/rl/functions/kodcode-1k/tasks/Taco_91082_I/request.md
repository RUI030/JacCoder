# longest_consecutive_sequence

I will give you a list of integers. Your task is to find the longest consecutive sequence of integers in the list and return the length of this sequence.

Example:

Input:
[100, 4, 200, 1, 3, 2]

Output:
The length of the longest consecutive sequence is 4 (the sequence is [1, 2, 3, 4]).

Example:
- `longest_consecutive_sequence([100, 4, 200, 1, 3, 2]) == 4`

Implement `longest_consecutive_sequence(nums: list[int]) -> int`.
