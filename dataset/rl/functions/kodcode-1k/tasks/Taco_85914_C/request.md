# parrot_repeats

Given a sentence ending with a full stop, return the sentence followed by the last word repeated twice.

>>> parrot_repeats("I love programming.")
'I love programming. programming programming'
>>> parrot_repeats("The parrot is very talkative.")
'The parrot is very talkative. talkative talkative'

Implement `parrot_repeats(sentence: str) -> str`.
