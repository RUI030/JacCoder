# is_merge

Determine if a given string `s` can be created by merging two other strings `part1` and `part2`.
All characters in `part1` and `part2` must appear in `s` in their original order.

>>> is_merge("codewars", "cdw", "oears")
True
>>> is_merge("codewars", "code", "wars")
True

Implement `is_merge(s: str, part1: str, part2: str) -> bool`.
