# sum_range

Create a function that takes in two integers, `num1` and `num2`, and returns the sum of all integers from `num1` to `num2` (inclusive). 
If `num1` is greater than `num2`, the function should return `-1` to indicate an error.

>>> sum_range(1, 5)
15
>>> sum_range(3, 3)
3

Implement `sum_range(num1: int, num2: int) -> int`.
