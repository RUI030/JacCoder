# can_make_arithmetic_progression

Checks if the given list can be rearranged to form an arithmetic progression.

:param nums: List of integers
:return: Boolean value indicating if the list can form an arithmetic progression

>>> can_make_arithmetic_progression([3, 5, 1])
True
>>> can_make_arithmetic_progression([1, 2, 4])
False

Implement `can_make_arithmetic_progression(nums: list[int]) -> bool`.
