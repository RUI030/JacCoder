# two_sum

Write a Jac function that takes a list of integers and a target integer as input. The function should return a tuple containing two distinct elements from the list that add up to the target, or None if no such pair exists. Assume that each input would have exactly one solution, and an element cannot be used twice. The input is the list [2, 7, 11, 15] and the target is 9.

Example:
- `two_sum([2, 7, 11, 15], 9) == (2, 7)`

Implement `two_sum(nums: list[int], target: int) -> tuple[int, int] | None`.
