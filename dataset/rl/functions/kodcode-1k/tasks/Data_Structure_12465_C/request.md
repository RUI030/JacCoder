# two_sum_with_edge_cases

Returns the indices of the two numbers such that they add up to the target.
If no such pair exists, return None.

>>> two_sum_with_edge_cases([2, 7, 11, 15], 9)
(0, 1)
>>> two_sum_with_edge_cases([3, 2, 4], 6)
(1, 2)

Implement `two_sum_with_edge_cases(array: list[int], target: int) -> tuple[int, int] | None`.
