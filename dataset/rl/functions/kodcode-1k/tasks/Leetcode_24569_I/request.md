# max_profit

You are given a **0-indexed** integer array `earrings` where each element represents the price of an earring in a jewelry shop. You are tasked with finding the **maximum possible profit** you can achieve by buying one earring and then selling it at a higher price on a later day. Return the _maximum profit_ you can achieve. If no profit can be achieved, return `0`.

Example:
- `max_profit([5]) == 0`

Implement `max_profit(earrings: list[int]) -> int`.
