# smallest_m

Given a list of `n` integers `arr`, find an integer `m` such that any integer between `1` and `m` (inclusive) can be written as the sum of one or more distinct elements from `arr`. Return the smallest possible value of `m` that meets the criteria.

Example:
- `smallest_m([1]) == 2`

Implement `smallest_m(arr: list[int]) -> int`.
