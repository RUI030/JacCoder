# int_to_bool_representation

Converts an integer to its boolean representation in string format.

Parameters:
- value (int): The integer to convert.

Returns:
- str: "True" if value is treated as True in Python, otherwise "False".

Example:
>>> int_to_bool_representation(1)
"True"
>>> int_to_bool_representation(0)
"False"

Implement `int_to_bool_representation(value: int) -> str`.
