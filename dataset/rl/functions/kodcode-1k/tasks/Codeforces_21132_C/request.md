# count_even_sum_pairs

Returns the number of pairs of indices (i, j) such that 1 ≤ i < j ≤ n
and the sum of array[i] and array[j] is an even number.

>>> count_even_sum_pairs(5, [1, 2, 3, 4, 5]) # Expected: 4
>>> count_even_sum_pairs(4, [2, 4, 6, 8]) # Expected: 6

Implement `count_even_sum_pairs(n: int, array: list[int]) -> int`.
