# describe_integer_with_text

Combines and returns the integer value and the text in a descriptive format.

>>> describe_integer_with_text(42, "Answer to the Ultimate Question")
'42 - Answer to the Ultimate Question'

>>> describe_integer_with_text(-10, "Negative number")
'-10 - Negative number'

Implement `describe_integer_with_text(value: int, text: str) -> str`.
