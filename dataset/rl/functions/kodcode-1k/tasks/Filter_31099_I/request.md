# insert_and_remove_duplicates

Given a list of numbers in increasing order, insert a new number such that the new list is still in increasing order. Additionally, the program should remove any duplicates in the final list. Implement this in an efficient way.

Example:
- `insert_and_remove_duplicates([1, 2, 3], 2) == [1, 2, 3]`

Implement `insert_and_remove_duplicates(sorted_list: list[int], new_number: int) -> list[int]`.
