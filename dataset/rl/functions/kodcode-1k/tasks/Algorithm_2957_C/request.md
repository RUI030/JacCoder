# add_polynomials

Adds two polynomials and returns the resulting polynomial in its simplified form.

Parameters:
poly1 (list of ints): Coefficients of the first polynomial.
poly2 (list of ints): Coefficients of the second polynomial.

Returns:
list of ints: Coefficients of the resulting polynomial.

Examples:
>>> add_polynomials([3, 0, 2], [1, 2, 1])
[4, 2, 3]
>>> add_polynomials([2, 3, 0, 0, 5], [1, -3, 2])
[3, 0, 2, 0, 5]

Implement `add_polynomials(poly1: list[int], poly2: list[int]) -> list[int]`.
