# longest_subarray_bitwise_and_greater_than_zero

Returns the length of the longest subarray where the bitwise AND of all elements is greater than zero.

>>> longest_subarray_bitwise_and_greater_than_zero(5, [12, 13, 7, 5, 9])
2
>>> longest_subarray_bitwise_and_greater_than_zero(1, [5])
1

Implement `longest_subarray_bitwise_and_greater_than_zero(n: int, arr: list[int]) -> int`.
