# find_two_sum

Write a Jac function that identifies any two distinct numbers in a list whose sum equals a specified target. The function should return the indices of these two numbers. If no such pair exists, the function should return an empty list.

Example:
- `find_two_sum([2, 7, 11, 15], 9) == [0, 1]`

Implement `find_two_sum(nums: list[int], target: int) -> list[int]`.
