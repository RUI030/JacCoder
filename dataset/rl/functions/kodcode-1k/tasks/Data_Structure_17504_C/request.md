# increment_digit_array

Increment a non-negative number represented as a list of digits by one.

Args:
    digits (List[int]): A list of integers representing the number.

Returns:
    List[int]: A new list of integers representing the incremented number.

Example:
>>> increment_digit_array([1, 2, 3])
[1, 2, 4]
>>> increment_digit_array([9, 9, 9])
[1, 0, 0, 0]

Implement `increment_digit_array(digits: list[int]) -> list[int]`.
