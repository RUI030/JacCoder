# min_operations_to_make_elements_equal

Returns the minimum number of operations required to make all elements of the array equal.
>>> min_operations_to_make_elements_equal(5, [1, 2, 3, 4, 5])
6
>>> min_operations_to_make_elements_equal(3, [10, 10, 10])
0

Implement `min_operations_to_make_elements_equal(n: int, arr: list[int]) -> int`.
