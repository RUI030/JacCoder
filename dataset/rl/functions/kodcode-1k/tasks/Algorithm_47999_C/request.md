# longest_multiple_subsequence

Given a list of integers, find the length of the longest subsequence such that each element in this subsequence is a multiple of the previous element in the subsequence.
>>> longest_multiple_subsequence([1, 2, 4, 8, 16, 3, 9, 27])
5
>>> longest_multiple_subsequence([3, 6, 4, 12, 24])
4

Implement `longest_multiple_subsequence(lst: list[int]) -> int`.
