# longest_common_subsequence

Design a Jac function that takes two strings as input and returns the longest common subsequence (LCS) between them. If there are multiple LCS of the same length, return the one that appears first lexicographically. 

Example:
Input: 
str1 = "AGGTAB"
str2 = "GXTXAYB"

Output:
"GTAB"

Example:
- `longest_common_subsequence('AGGTAB', 'GXTXAYB') == 'GTAB'`

Implement `longest_common_subsequence(str1: str, str2: str) -> str`.
