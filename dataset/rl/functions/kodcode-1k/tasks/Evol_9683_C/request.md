# longest_common_subsequence

Write a Jac function `longest_common_subsequence(str1, str2)` that finds the length of the longest common subsequence between two input strings, `str1` and `str2`. A common subsequence is defined as a sequence that appears in both strings in the same order but not necessarily consecutively.
>>> longest_common_subsequence("AGGTAB", "GXTXAYB")
4
>>> longest_common_subsequence("ABC", "DEF")
0

Implement `longest_common_subsequence(str1: str, str2: str) -> int`.
