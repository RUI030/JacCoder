# find_first_occurrence

Returns the index of the first occurrence of string in the list.
If the string is not found, returns -1.

>>> find_first_occurrence(["apple", "banana", "cherry"], "banana") == 1
>>> find_first_occurrence(["apple", "banana", "cherry"], "apple") == 0

Implement `find_first_occurrence(lst: list[str], string: str) -> int`.
