# count_distinct_permutations

Write a function that takes a string as input and returns the number of distinct permutations of the characters in the string. Your function should be efficient enough to handle strings of up to 20 characters, including repeat characters.

>>> count_distinct_permutations('abc')
6
>>> count_distinct_permutations('a')
1

Implement `count_distinct_permutations(s: str) -> int`.
