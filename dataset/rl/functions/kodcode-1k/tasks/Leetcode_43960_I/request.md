# three_sum

Given an array of `n` integers `nums`, determine if there exists a triplet `(i, j, k)` with `0 <= i < j < k < n` such that `nums[i] + nums[j] + nums[k] = 0`. If such a triplet exists, return all the unique triplets that sum up to zero, otherwise return an empty list. Note that the solution set must not contain duplicate triplets.

Example:
- `three_sum([1, 2, -2, -1]) == []`

Implement `three_sum(nums: list[int]) -> list[list[int]]`.
