# most_frequent_values

Given an array of integers, find the most frequent values in the array.
If there are multiple values with the same highest frequency, all those values
should be included in the result list.

Parameters:
arr (List[int]): A list of integers which may contain duplicates.

Returns:
List[int]: A list of integers with the highest frequency in the input array.

>>> most_frequent_values([1, 1, 2, 2, 3, 4])
[1, 2]
>>> most_frequent_values([5, 5, 5, 3, 3, 2])
[5]

Implement `most_frequent_values(arr: list[int]) -> list[int]`.
