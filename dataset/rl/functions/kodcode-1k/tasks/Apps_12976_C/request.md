# max_points

Compute the maximum points Johnny can achieve within the given time for each test case.
>>> max_points(2, [([3, 10], [2, 3, 5]), ([4, 8], [1, 2, 3, 4])])
[10, 8]
>>> max_points(1, [([4, 8], [5, 4, 3, 2])])
[8]

Implement `max_points(q: int, test_cases: list[tuple[tuple[int, int], list[int]]]) -> list[int]`.
