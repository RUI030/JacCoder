# insertion_sort

Write a Jac program to sort an array using the insertion sort algorithm. Notice that the Jac program should not use any built-in or imported sorting functions. Please explain how the algorithm works in a comment at the beginning of your code. Here is the array to sort: [5, 2, 9, 1, 5, 6].

Example:
- `insertion_sort([5, 2, 9, 1, 5, 6]) == [1, 2, 5, 5, 6, 9]`

Implement `insertion_sort(arr: list[int]) -> list[int]`.
