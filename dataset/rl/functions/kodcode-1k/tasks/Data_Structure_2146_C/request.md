# find_unique_product_id

Returns the unique product ID that appears only once in the list of product IDs
while every other ID appears exactly twice.

>>> find_unique_product_id([4, 1, 2, 1, 2])
4
>>> find_unique_product_id([7, 3, 5, 4, 5, 3, 7])
4

Implement `find_unique_product_id(product_ids: list[int]) -> int`.
