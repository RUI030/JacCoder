# smallest_repeated_number

Identifies and returns the smallest integer in a given list of numbers that appears more than once.
If no such number exists, returns None.
>>> smallest_repeated_number([4, 2, 3, 4, 1, 2]) 2
>>> smallest_repeated_number([1, 2, 3, 4, 5]) None

Implement `smallest_repeated_number(numbers: list[int]) -> int | None`.
