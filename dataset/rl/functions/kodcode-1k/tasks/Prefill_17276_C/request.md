# first_digit_sum

Calculate the First Digit Sum (FDS) of a given number. The FDS is the sum of the digits of the integer part of the number.
The fractional part is ignored. If the number is negative, convert it to a positive number before the calculation.

>>> first_digit_sum(123)
6
>>> first_digit_sum(123.45)
6

Implement `first_digit_sum(num: float) -> int`.
