# collatz_steps

Calculates the number of steps required for the Collatz sequence to reach 1.

Parameters:
n (int): A positive integer to start the sequence.

Returns:
int: The number of steps required to reach 1.

Examples:
>>> collatz_steps(6)
8
>>> collatz_steps(1)
0

Implement `collatz_steps(n: int) -> int`.
