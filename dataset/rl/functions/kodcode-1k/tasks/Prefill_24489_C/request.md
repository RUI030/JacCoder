# filter_strings_starting_with

Create a function that takes two arguments: a list of strings and a character.
The function should return a new list containing only the strings from the original list that start with the given character.

>>> filter_strings_starting_with([], 'a')
[]
>>> filter_strings_starting_with(['apple', 'banana', 'cherry'], 'd')
[]

Implement `filter_strings_starting_with(strings: list[str], char: str) -> list[str]`.
