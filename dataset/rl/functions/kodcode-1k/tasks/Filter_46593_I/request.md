# string_to_ascii_list

Write a Jac function to convert a given string into a list of ASCII values. The function should take a single string as input and return a list of integers, where each integer is the ASCII value of the corresponding character in the input string. For example, the string "abc" should return the list [97, 98, 99].

Example:
- `string_to_ascii_list('') == []`

Implement `string_to_ascii_list(s: str) -> list[int]`.
