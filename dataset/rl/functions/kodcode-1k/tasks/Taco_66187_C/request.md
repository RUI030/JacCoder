# subarray_sum

Determine if there is a subarray that sums to a given target value.

Args:
arr (List[int]): The input array of integers.
target (int): The target sum value.

Returns:
bool: True if such a subarray exists, False otherwise.

Examples:
>>> subarray_sum([1, 2, 3, 7, 5], 12)
True
>>> subarray_sum([1, 2, 3, 4, 5], 9)
True

Implement `subarray_sum(arr: list[int], target: int) -> bool`.
