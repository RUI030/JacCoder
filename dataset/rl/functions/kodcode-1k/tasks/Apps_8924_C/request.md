# findCommonElements

Returns a sorted list of common elements without duplicates between list1 and list2.

Examples:
>>> findCommonElements([1, 2, 2, 3, 4], [3, 4, 4, 5, 6])
[3, 4]
>>> findCommonElements([7, 8, 9], [9, 10, 11, 7])
[7, 9]

Implement `findCommonElements(list1: list[int], list2: list[int]) -> list[int]`.
