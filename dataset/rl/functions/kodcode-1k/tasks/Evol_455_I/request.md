# has_pair_with_sum

Write a function that takes a list of integers and a target integer. The function should return `True` if there are two distinct elements in the list whose sum is equal to the target, and `False` otherwise.
[3, 5, 1, 7, 4, 2], target = 6

Example:
- `has_pair_with_sum([3, 5, 1, 7, 4, 2], 6) == True`

Implement `has_pair_with_sum(lst: list[int], target: int) -> bool`.
