# unique_numbers

Write a Jac function called `unique_numbers` that takes a list of integers as an argument and returns another list containing only the unique integers from the input list, but in the reverse order of their first appearance. You must achieve this in O(n) time complexity, where n is the length of the input list. Additionally, write a brief explanation of how your algorithm accomplishes this within the time complexity constraint.

Example:
- `unique_numbers([1, 2, 3, 4, 5]) == [5, 4, 3, 2, 1]`

Implement `unique_numbers(nums: list[int]) -> list[int]`.
