# first_non_repeating_character

Write a function that takes a string as input and returns the first non-repeating character in it. 
If all characters are repeating or the string is empty, return an underscore. 
The function should be case-sensitive.

>>> first_non_repeating_character("swiss")
'w'
>>> first_non_repeating_character("aabbcc")
'_'

Implement `first_non_repeating_character(s: str) -> str`.
