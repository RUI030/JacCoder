# calculate_factorial

Write a function to calculate the factorial of a given number. The function should be named `calculate_factorial` and it should take one parameter, `number`. The function should return the factorial of the number. If the number is 0, the function should return 1, as 0! = 1. If the number is negative, the function should return `None`, as factorials for negative numbers are not defined.

Example:
- `calculate_factorial(5) == 120`

Implement `calculate_factorial(number: int) -> int | None`.
