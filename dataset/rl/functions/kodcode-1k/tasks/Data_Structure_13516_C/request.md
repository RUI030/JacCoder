# coupon_combinations

This function returns the number of possible combinations of given coupon values that sum up to the target discount.

Args:
nums (List[int]): A list of positive integers representing coupon values.
target (int): An integer representing the target discount amount.

Returns:
int: The number of different combinations that add up to the target discount.

Examples:
>>> coupon_combinations([1, 2, 3], 4)
7
>>> coupon_combinations([2, 3, 6, 7], 7)
4

Implement `coupon_combinations(nums: list[int], target: int) -> int`.
