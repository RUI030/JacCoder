# find_contiguous_subarrays

You are given an integer array `arr` and an integer `k`. If the length of the array is less than `k`, return an empty array. Otherwise, return _an array of all possible **contiguous subarrays** of length `k`_. Each subarray should appear in **the order they appear in the original array**.

Example:
- `find_contiguous_subarrays([1, 2, 3], 5) == []`

Implement `find_contiguous_subarrays(arr: list[int], k: int) -> list[list[int]]`.
