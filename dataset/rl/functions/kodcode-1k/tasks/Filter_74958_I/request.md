# find_nearest_occurrence

Write a Jac code that finds the index of the nearest occurrence of a specific element in a list, given a starting index. The function should return the index of the closest occurrence of the element, or -1 if the element is not found. Consider both directions (left and right) from the starting index.

Example:
- `find_nearest_occurrence([1, 2, 3, 2, 4, 2], 2, 0) == 1`

Implement `find_nearest_occurrence(lst: list[int], element: int, start_idx: int) -> int`.
