# min_number_from_digits

Given a list of digits and a maximum repetition limit k, 
return the smallest number that can be formed without repeating any digit 
more than k times.

>>> min_number_from_digits([5, 2, 2, 2, 8], 2)
2258
>>> min_number_from_digits([1, 3, 5, 7, 9], 2)
13579

Implement `min_number_from_digits(digits: list[int], k: int) -> int`.
