# can_sort_by_adjacent_swaps

You are given an integer array `nums` containing `n` unique numbers in the range from `1` to `n`. The array may be shuffled and may contain any permutation of these numbers. Your task is to determine if it is possible to sort this array in ascending order by performing a series of operations. In one operation, you can choose any two adjacent elements and swap them. Return `true` if you can sort the array using these operations, otherwise return `false`.

Example:
- `can_sort_by_adjacent_swaps([1, 2, 3, 4, 5]) == True`

Implement `can_sort_by_adjacent_swaps(nums: list[int]) -> bool`.
