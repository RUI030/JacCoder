# word_count

Given a string, return a map where each word is a key and the value is the number of times that word appears in the string. Ignore case sensitivity and punctuation.
Example: "Hello world, hello! This is a test. Hello, world..."
Output: {"hello": 3, "world": 2, "this": 1, "is": 1, "a": 1, "test": 1}

Example:
- `word_count('Hello') == {'hello': 1}`

Implement `word_count(s: str) -> dict[str, int]`.
