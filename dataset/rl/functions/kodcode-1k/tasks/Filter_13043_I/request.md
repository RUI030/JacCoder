# is_string_in_list

I provide a list of strings ( ["hello", "world", "python"] ) and a single string ("python"). I want to check if the single string is in the list of strings. 
I can do this using a for loop in python that checks each string in the list against the single string, but is there a more "pythonic" way of doing this?

Example:
- `is_string_in_list(['hello', 'world', 'python'], 'python') == True`

Implement `is_string_in_list(lst: list[str], single_str: str) -> bool`.
