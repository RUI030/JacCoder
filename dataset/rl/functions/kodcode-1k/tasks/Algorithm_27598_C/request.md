# is_balanced

Returns whether the given string of parentheses is balanced.

Parameters:
    s (str): A string containing only the characters '(', ')', '[', ']', '{', '}'.

Returns:
    bool: True if the string is balanced, False otherwise.

>>> is_balanced("()[]{}")
True
>>> is_balanced("([{}])")
True

Implement `is_balanced(s: str) -> bool`.
