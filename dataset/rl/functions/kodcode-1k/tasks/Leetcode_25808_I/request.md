# sum_even_nums_or_even_index

You are given a 0-indexed integer array `nums` of length `n`. Your task is to return the sum of all elements that are either even or appear at an even index. Implement a function that calculates this sum.

Example:
- `sum_even_nums_or_even_index([2, 4, 6, 8, 10]) == 30`

Implement `sum_even_nums_or_even_index(nums: list[int]) -> int`.
