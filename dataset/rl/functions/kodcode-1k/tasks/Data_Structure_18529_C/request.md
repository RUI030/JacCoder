# find_min_ignore_duplicates

Finds the minimum element in a rotated sorted array.

:param arr: List of unique integers representing a rotated sorted array.
:return: The minimum element in the array.

>>> find_min_ignore_duplicates([4, 5, 6, 7, 0, 1, 2])
0
>>> find_min_ignore_duplicates([1])
1

Implement `find_min_ignore_duplicates(arr: list[int]) -> int`.
