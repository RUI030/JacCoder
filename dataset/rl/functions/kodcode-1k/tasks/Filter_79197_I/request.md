# is_even_and_prime

Write a Jac function named `is_even_and_prime` that checks if a given number is both even and prime. The function should return `True` if the number is both even and prime, and `False` otherwise. Note that 2 is the only number that is both even and prime.

Example:
- `is_even_and_prime(2) == True`

Implement `is_even_and_prime(n: int) -> bool`.
