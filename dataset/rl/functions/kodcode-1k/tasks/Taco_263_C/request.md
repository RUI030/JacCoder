# longest_same_parity_subarray

Returns the length of the longest contiguous subarray where all elements have the same parity (odd or even).
>>> longest_same_parity_subarray([1, 2, 4, 6, 5, 7, 8]) == 3
>>> longest_same_parity_subarray([1, 3, 5, 2, 4, 6, 8, 7, 9]) == 4

Implement `longest_same_parity_subarray(nums: list[int]) -> int`.
