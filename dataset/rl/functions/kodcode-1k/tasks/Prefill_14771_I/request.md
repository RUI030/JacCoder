# sum_in_range

Create a function that takes an integer array and return the sum of elements within a given range (start and end indices). The function should handle cases where the start index is greater than the end index by returning null. If the range is out of bounds, it should return null.

Example:
- `sum_in_range([1, 2, 3, 4, 5], 1, 3) == 9`

Implement `sum_in_range(arr: list[int], start: int, end: int) -> int | None`.
