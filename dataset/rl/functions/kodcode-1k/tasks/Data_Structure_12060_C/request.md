# enhanced_selection_sort

Enhanced Selection Sort with Early Termination
Args:
- arr: List[int], the list of integers to sort

Returns:
- List[int], the sorted list

>>> enhanced_selection_sort([64, 25, 12, 22, 11])
[11, 12, 22, 25, 64]
>>> enhanced_selection_sort([4, 3, 2, 1, 0])
[0, 1, 2, 3, 4]

Implement `enhanced_selection_sort(arr: list[int]) -> list[int]`.
