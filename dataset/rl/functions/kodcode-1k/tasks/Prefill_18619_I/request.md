# fibonacci_sequence

Create a function that will take an integer `n` as a parameter and return an `ArrayList<Integer>` of length `n`, where each element is a Fibonacci number. The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones, usually starting with 0 and 1. The sequence goes: 0, 1, 1, 2, 3, 5, 8, 13, ...

Example:
- `fibonacci_sequence(0) == []`

Implement `fibonacci_sequence(n: int) -> list[int]`.
