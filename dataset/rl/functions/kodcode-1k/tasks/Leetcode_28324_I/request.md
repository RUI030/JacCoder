# trap

You are given a list of non-negative integers representing the heights of blocks where the width of each block is 1. Compute how much water can be trapped between the blocks after a rain. Implement a function `trap` that takes an array `height` as an input and returns an integer representing the total amount of water that can be trapped. The function should handle cases efficiently where the length of the list can be large.

Example:
- `trap([]) == 0`

Implement `trap(height: list[int]) -> int`.
