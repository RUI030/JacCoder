# num_decodings

Determine the total number of ways to decode a string of digits according to the mapping 'A' -> 1, 'B' -> 2, ..., 'Z' -> 26.

Args:
s (str): A string of digits to decode.

Returns:
int: The number of ways to decode the string.

Examples:
>>> num_decodings("12")
2
>>> num_decodings("226")
3

Implement `num_decodings(s: str) -> int`.
