# is_palindrome

Write a Jac script that takes a string input from the user and checks if the string is a palindrome. A palindrome is a word, phrase, number, or other sequence of characters that reads the same backward as forward, such as "madam" or "racecar". The script should ignore case sensitivity and non-alphanumeric characters. Display a message to the user indicating whether the input is a palindrome or not.

Example:
- `is_palindrome('madam') == True`

Implement `is_palindrome(input_str: str) -> bool`.
