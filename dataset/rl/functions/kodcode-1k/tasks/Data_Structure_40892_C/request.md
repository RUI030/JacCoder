# is_match

Determines if the input string s matches the pattern p.

Parameters:
s (str): Input string consisting of lowercase letters.
p (str): Pattern string consisting of lowercase letters, '.' and '*'.

Returns:
bool: True if the input string matches the pattern string, otherwise False.

Examples:
>>> is_match("aa", "a")
False
>>> is_match("aa", "aa")
True

Implement `is_match(s: str, p: str) -> bool`.
