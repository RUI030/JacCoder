# max_sum_of_k_consecutive

Given an integer array `nums` and an integer `k`, return the maximum sum of `k` consecutive elements in the array. If `nums` has fewer than `k` elements, return `-1`. Try to solve the problem in O(n) time complexity.

Example:
- `max_sum_of_k_consecutive([1, 2, 3, 4, 5], 2) == 9`

Implement `max_sum_of_k_consecutive(nums: list[int], k: int) -> int`.
