# binary_search

Given a sorted array of integers and an integer value, figure out whether the given value is present in the array or not using a binary search algorithm. If the value is present, return the index at which it is found. Additionally, calculate the time complexity of your solution.

Example:
- `binary_search([1, 2, 3, 4, 5], 3) == 2`

Implement `binary_search(arr: list[int], value: int) -> int`.
