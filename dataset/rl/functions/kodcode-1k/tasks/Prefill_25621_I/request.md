# binomial_coefficient

Create a function that calculates the binomial coefficient for given integers n and k. The function should handle large values of n and k efficiently. The binomial coefficient, often denoted as "n choose k" or C(n, k), is defined as the number of ways to choose k elements from a set of n distinct elements.

Example:
- `binomial_coefficient(5, 0) == 1`

Implement `binomial_coefficient(n: int, k: int) -> int`.
