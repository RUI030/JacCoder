# common_elements

Write a function that takes in two lists of integers and returns a new list that contains only the common elements between the two input lists, but the common elements should appear in the order that they appear in the first list. The input lists may contain duplicate elements, but the output list should not have any duplicates.

Example:
- `common_elements([1, 2, 3], [4, 5, 6]) == []`

Implement `common_elements(list1: list[int], list2: list[int]) -> list[int]`.
