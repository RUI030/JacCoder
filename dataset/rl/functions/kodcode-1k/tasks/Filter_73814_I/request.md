# max_subarray_sum

Write a Jac function to find the maximum sum of a subarray within a given one-dimensional array of integers. This problem is known as the "Maximum Subarray Problem." Implement your solution using Kadane's Algorithm, which is efficient with a time complexity of O(n).

Example:
- `max_subarray_sum([1]) == 1`

Implement `max_subarray_sum(arr: list[int]) -> int`.
