# cocktail_shaker_sort

Sorts a list of integers using the Cocktail Shaker Sort algorithm.

Args:
arr (list): A list of integers to be sorted.

Returns:
list: The sorted list in non-decreasing order.

Examples:
>>> cocktail_shaker_sort([3, 0, 2, 5, -1, 4, 1])
[-1, 0, 1, 2, 3, 4, 5]

>>> cocktail_shaker_sort([5, 3, 1, 2, 4])
[1, 2, 3, 4, 5]

Implement `cocktail_shaker_sort(arr: list[int]) -> list[int]`.
