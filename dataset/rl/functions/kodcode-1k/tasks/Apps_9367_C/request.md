# find_smallest_missing_positive_integer

Write a function that takes an array of integers and returns the smallest positive integer that does not appear in the array. The array can be empty or contain positive and negative integers. Do not use built-in sorting functions to solve this problem. Aim for a solution with linear time complexity.

>>> find_smallest_missing_positive_integer([]) == 1
>>> find_smallest_missing_positive_integer([1, 2, 3, 4, 5]) == 6

Implement `find_smallest_missing_positive_integer(arr: list[int]) -> int`.
