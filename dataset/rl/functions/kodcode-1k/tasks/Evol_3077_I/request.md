# first_non_repeated_character

Write a function that takes a string of text and returns the first non-repeated character. If all characters in the string are repeated, return an underscore. Ensure the function handles both uppercase and lowercase letters as distinct characters. For example, given the input "teeter", the function should return "r".

Example:
- `first_non_repeated_character('teeter') == 'r'`

Implement `first_non_repeated_character(text: str) -> str`.
