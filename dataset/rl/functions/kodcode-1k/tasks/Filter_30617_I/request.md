# delete_all_occurrences

What is the command to delete all occurrences of the element "5" from a given Python array, without using any built-in Jac functions or methods such as pop(), remove(), or filter() and maintaining the order of the other elements? Additionally, ensure that the algorithm has a time complexity of O(n) and a space complexity of O(1), where n is the length of the array.

Example:
- `delete_all_occurrences([1, 2, 5, 3, 5, 4], 5) == [1, 2, 3, 4]`

Implement `delete_all_occurrences(arr: list[int], element: int) -> list[int]`.
