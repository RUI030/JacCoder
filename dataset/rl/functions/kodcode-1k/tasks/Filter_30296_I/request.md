# sort_list

Assume I have a list named 'x' that has the following data: [9, 5, 2, 6, 3]. I want to sort this list and print all the numbers in ascending order. Can you write a simple Jac script to solve this problem? Additionally, can you encapsulate this functionality in a function that accepts any list of integers and returns a sorted version of that list?

Example:
- `sort_list([9, 5, 2, 6, 3]) == [2, 3, 5, 6, 9]`

Implement `sort_list(x: list[int]) -> list[int]`.
