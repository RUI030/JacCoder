# find_pair_with_sum

Finds two distinct numbers in the sorted array 'numbers' that add up to 'target'.
Returns the 1-based indices of these two numbers. If no pair is found, returns an empty list.
Examples:
>>> find_pair_with_sum([2, 7, 11, 15], 9)
[1, 2]
>>> find_pair_with_sum([1, 2, 3, 4, 6], 10)
[4, 5]

Implement `find_pair_with_sum(numbers: list[int], target: int) -> list[int]`.
