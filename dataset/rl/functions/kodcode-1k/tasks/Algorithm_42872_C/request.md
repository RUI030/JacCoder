# is_permutation_of_palindrome

Determines if the given string is a permutation of a palindrome.

Args:
s (str): Input string.

Returns:
bool: True if the string is a permutation of a palindrome, False otherwise.

>>> is_permutation_of_palindrome("Tact Coa")
True
>>> is_permutation_of_palindrome("aab")
True

Implement `is_permutation_of_palindrome(s: str) -> bool`.
