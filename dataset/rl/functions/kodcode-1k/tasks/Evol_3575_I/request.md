# product_except_self

Write a function that takes a list of integers and returns a new list where each element is the product of all the integers in the original list except the one at the current index. For example, given the list `[1, 2, 3, 4]`, the output should be `[24, 12, 8, 6]`. Note: Division is not allowed to solve this problem.

Example:
- `product_except_self([1, 2, 3, 4]) == [24, 12, 8, 6]`

Implement `product_except_self(nums: list[int]) -> list[int]`.
