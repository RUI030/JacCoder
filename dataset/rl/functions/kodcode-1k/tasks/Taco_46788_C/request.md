# min_operations_to_make_subsequence

Determine the minimum number of operations required to make s1 a subsequence of s2.

>>> min_operations_to_make_subsequence("abc", "bahbgdc")
0
>>> min_operations_to_make_subsequence("axc", "bahbgdc")
2

Implement `min_operations_to_make_subsequence(s1: str, s2: str) -> int`.
