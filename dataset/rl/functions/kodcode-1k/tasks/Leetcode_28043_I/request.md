# max_songs

You are given a list of songs and their respective durations in the form of an integer array `durations`, where `durations[i]` represents the duration of the `i-th` song. You are also given an integer `totalTime` which represents the total duration a playlist should not exceed. Your task is to determine the maximum number of songs that can be included in such a playlist without exceeding the given `totalTime`. Return the _maximum number of songs_ that can be included.

Example:
- `max_songs([3, 5, 4, 11, 6], 17) == 3`

Implement `max_songs(durations: list[int], totalTime: int) -> int`.
