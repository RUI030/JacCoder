# longest_palindrome_length

Alice wants to create the longest possible palindrome using the characters from a given string.
She is allowed to rearrange the characters of the string if necessary.
This function calculates the length of the longest palindrome that can be constructed using the characters of the input string.

>>> longest_palindrome_length("abccccdd")
7
>>> longest_palindrome_length("a")
1

Implement `longest_palindrome_length(s: str) -> int`.
