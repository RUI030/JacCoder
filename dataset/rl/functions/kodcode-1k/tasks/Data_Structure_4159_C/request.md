# custom_bucket_sort

Sorts a list of floating-point numbers between 0 and 1 in ascending order using bucket sort algorithm.
>>> custom_bucket_sort([0.23, 0.45, 0.12, 0.36, 0.29])
[0.12, 0.23, 0.29, 0.36, 0.45]
>>> custom_bucket_sort([])
[]

Implement `custom_bucket_sort(arr: list[float]) -> list[float]`.
