# reverse_and_capitalize

Write a Jac function that accepts a string containing a sequence of words separated by spaces. The function should reverse the order of the words and capitalize the first letter of each word in the reversed string. Do not use any built-in functions to reverse the string or capitalize the words. Also, the function should remove any extra spaces between words in the given string. Your function should return the modified string as output.

Example:
- `reverse_and_capitalize('hello') == 'Hello'`

Implement `reverse_and_capitalize(sentence: str) -> str`.
