# ostrich_escape

Write a Jac function `ostrich_escape(l, trouble_places, foot_mode)`. This function determines whether a group of ostriches can escape their enclosure without touching any of the trouble spots during a risky escape plan.

Example:
- `ostrich_escape(10, [], [1, 2, 3, 4, 5]) == True`

Implement `ostrich_escape(l: int, trouble_places: list[int], foot_mode: list[int]) -> bool`.
