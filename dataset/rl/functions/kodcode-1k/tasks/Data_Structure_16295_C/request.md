# longest_common_subsequence

Write a function that takes two strings `a` and `b` as input, where string `b` contains
all distinct characters, and returns the length of the longest common subsequence (LCS) between them.

>>> longest_common_subsequence("abcde", "ace")
3
>>> longest_common_subsequence("abc", "abc")
3

Implement `longest_common_subsequence(a: str, b: str) -> int`.
