# count_unique_words

Write a Jac function to find the number of unique words in a given sentence. The function should consider words as case-insensitive and also ignore simple punctuation marks like commas and periods at the end of words. For example, "Hello," and "hello" should be considered the same word.

Example:
- `count_unique_words('') == 0`

Implement `count_unique_words(sentence: str) -> int`.
