# filter_elements

Write a function in Python that takes a list as input and returns a new list with all elements unique, maintained in their original order of appearance, and filtering out those elements which appear more than a specified frequency.

Example:
- `filter_elements([1, 2, 3, 4, 5], 1) == [1, 2, 3, 4, 5]`

Implement `filter_elements(lst: list[int], frequency: int) -> list[int]`.
