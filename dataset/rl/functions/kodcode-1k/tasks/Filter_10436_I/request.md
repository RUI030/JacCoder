# transform_list

I have a function `func` that returns a list of integers. How do I use list comprehension to transform this list into a new list that contains the squares of the original list's elements, but only for the even numbers?

Example:
- `transform_list([1, 2, 3, 4, 5, 6]) == [4, 16, 36]`

Implement `transform_list(input_list: list[int]) -> list[int]`.
