# max_sum_of_m_subarrays

Given an integer array `arr` and an integer `m`, return the maximum sum of `m` non-overlapping subarrays of length `k`. The subarrays should not overlap, meaning that the same elements may not be reused in multiple subarrays. You must implement an efficient algorithm with a time complexity better than `O(n^2)`, where `n` is the length of `arr`.

Example:
- `max_sum_of_m_subarrays([1, 2, 3, 4, 5], 2, 2) == 14`

Implement `max_sum_of_m_subarrays(arr: list[int], k: int, m: int) -> int`.
