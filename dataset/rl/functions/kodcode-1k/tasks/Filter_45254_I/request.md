# reverse_string

Write a Jac function to reverse a given string. The function should take a single string argument and return the reversed string. Ensure your function is well-documented and includes a docstring explaining what it does. Also, provide a simple check function to test your reverse function with a few test cases to verify its correctness.

Example:
- `reverse_string('hello') == 'olleh'`

Implement `reverse_string(s: str) -> str`.
