# count_strings

Write a function in Python that takes a list of strings and returns a dictionary where the keys are the unique strings from the list and the values are the number of times each string appears.

Example:
- `count_strings(['a', 'b', 'c']) == {'a': 1, 'b': 1, 'c': 1}`

Implement `count_strings(strings: list[str]) -> dict[str, int]`.
