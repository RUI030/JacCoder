# trap_rainwater

You are given a list of non-negative integers `nums` which represents the amount of rainwater trapped at each elevation map where the width of each bar is 1. Compute how much water it can trap after raining.

For example:
Given `nums = [0,1,0,2,1,0,1,3,2,1,2,1]`, return `6`.

Note: 
* It is guaranteed that `nums` will have at least one element and each element will be a non-negative integer.

Example:
- `trap_rainwater([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]) == 6`

Implement `trap_rainwater(nums: list[int]) -> int`.
