# max_profit

Write a function that takes a list of integers representing daily stock prices 
and returns the maximum profit that could have been made by buying on one day 
and selling on another. If no profit can be made, return 0.

>>> max_profit([7, 1, 5, 3, 6, 4])
5
>>> max_profit([7, 6, 5, 4, 3, 2, 1])
0

Implement `max_profit(prices: list[int]) -> int`.
