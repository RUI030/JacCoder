# intersection

Compute the intersection of two lists of integers.
The resulting list of the intersection should contain unique elements that are present in both input lists.

>>> intersection([4, 9, 5], [9, 4, 9, 8, 4])
[4, 9]
>>> intersection([1, 2, 2, 1], [2, 2])
[2]

Implement `intersection(arr1: list[int], arr2: list[int]) -> list[int]`.
