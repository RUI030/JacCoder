# calculate_trapped_water

Calculate the total amount of water trapped between buildings after a rainstorm.

:param heights: List[int] - A list of non-negative integers representing the heights of buildings.
:return: int - The total amount of water trapped.

Examples:
>>> calculate_trapped_water([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])
6
>>> calculate_trapped_water([4, 2, 0, 3, 2, 5])
9

Implement `calculate_trapped_water(heights: list[int]) -> int`.
