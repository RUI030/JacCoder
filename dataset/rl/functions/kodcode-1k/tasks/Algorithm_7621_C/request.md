# sort_by_length

Sorts a list of strings in decreasing order of their lengths.

Args:
strings (List[str]): The list of strings to sort.

Returns:
List[str]: The sorted list of strings by decreasing length.

Examples:
>>> sort_by_length(["apple", "banana", "pear", "grape"])
["banana", "apple", "grape", "pear"]

>>> sort_by_length(["a", "abc", "abcd", "ab", "abcdef"])
["abcdef", "abcd", "abc", "ab", "a"]

Implement `sort_by_length(strings: list[str]) -> list[str]`.
