# unobstructed_view

Returns the number of buildings that have an unobstructed view of the sunset.

Args:
buildings (List[int]): An array of integers representing the heights of the buildings.

Returns:
int: The number of buildings with an unobstructed view of the sunset.

Examples:

>>> unobstructed_view([3, 4, 2, 5, 1])
3
>>> unobstructed_view([5])
1

Implement `unobstructed_view(buildings: list[int]) -> int`.
