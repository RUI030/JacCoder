# longest_winning_streak

You are given a list of integers `nums` representing the number of points each player scored in a series of games. A player who scores more than the previous one is considered to have a "winning streak". Return the **length** of the longest winning streak in the series. If there is no winning streak, return 0.

Example:
- `longest_winning_streak([1, 2, 3, 4, 5]) == 5`

Implement `longest_winning_streak(nums: list[int]) -> int`.
