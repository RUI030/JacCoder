# sort_in_wave

Write a function to sort an array in a wave-like order. Wave-like order is defined as an array where every pair of adjacent elements are in opposite order. The elements in the resultant array more or less appear in a wave pattern. For example, a wave-like order for an array could be A< B > C< D > E< F > so on. Given an array, sort the array in wave order by swapping the elements as required.

Example:
- `sort_in_wave([3, 6, 5, 10, 7, 20]) == [6, 3, 10, 5, 20, 7]`

Implement `sort_in_wave(arr: list[int]) -> list[int]`.
