# reverse_words_with_punctuation

Reverses the order of words in a sentence, 
while preserving punctuation attached to words and extra spaces between words.

Parameters:
sentence (str): The input string containing words with punctuation.

Returns:
str: The sentence with words in reversed order and punctuation correctly attached to words.

Examples:
>>> reverse_words_with_punctuation("Hello, world!") 
"world! Hello,"
>>> reverse_words_with_punctuation("I love Python, very much!")
"much! very Python, love I"

Implement `reverse_words_with_punctuation(sentence: str) -> str`.
