# strings_to_length_dict

Create a Jac function that takes a list of strings as input and returns a dictionary where each key is a string from the input list and the value is the length of that string. If the list contains duplicate strings, the dictionary should only include them once. Ensure your code snippet is self-contained, with all necessary imports, and follows the guidelines provided. Also, include a function to test the correctness of your solution with given data points.

Example:
- `strings_to_length_dict(['apple', 'banana', 'cherry']) == {'apple': 5, 'banana': 6, 'cherry': 6}`

Implement `strings_to_length_dict(strings: list[str]) -> dict[str, int]`.
