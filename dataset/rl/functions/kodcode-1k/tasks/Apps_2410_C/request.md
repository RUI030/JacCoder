# maximizeDifference

Given a list of integers, sort the list in alternating high and low order
such that the first integer is the largest, the second is the smallest, the
third is the second largest, and so on.

>>> maximizeDifference([4, 3, 2, 1]) [4, 1, 3, 2]
>>> maximizeDifference([10, 5, 3, 8, 9, 2]) [10, 2, 9, 3, 8, 5]

Implement `maximizeDifference(nums: list[int]) -> list[int]`.
