# rotate_list

Rotate a list of integers to the right by k steps.

Parameters:
nums (list of int): The list of integers to be rotated.
k (int): The number of steps to rotate the list to the right.

Returns:
list of int: The rotated list.

Examples:
>>> rotate_list([1, 2, 3, 4, 5, 6, 7], 3)
[5, 6, 7, 1, 2, 3, 4]
>>> rotate_list([-1, -100, 3, 99], 2)
[3, 99, -1, -100]

Implement `rotate_list(nums: list[int], k: int) -> list[int]`.
