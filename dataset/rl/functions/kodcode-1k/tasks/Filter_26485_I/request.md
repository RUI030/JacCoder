# binary_search_rotated

Write an algorithm for implementing binary search on a rotated sorted array. The array has been shifted an unknown number of times. Include error checking for invalid inputs and handle cases where the array is not rotated at all.

Example:
- `binary_search_rotated([4, 5, 6, 7, 0, 1, 2], 0) == 4`

Implement `binary_search_rotated(arr: list[int], target: int) -> int`.
