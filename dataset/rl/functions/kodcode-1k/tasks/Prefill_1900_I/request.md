# roman_to_int

Write a function to convert a Roman numeral to an integer. The function should take a string as input and return the corresponding integer. The Roman numeral string is given in capital letters (e.g., "III" for 3, "IV" for 4, "IX" for 9, etc.).

Example:
- `roman_to_int('I') == 1`

Implement `roman_to_int(s: str) -> int`.
