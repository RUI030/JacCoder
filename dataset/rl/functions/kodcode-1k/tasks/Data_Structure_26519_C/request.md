# advanced_reverse

Efficiently reverses a string without using Python built-in slicing or reversed functions.

Args:
    s (str): The input string to be reversed.

Returns:
    str: The reversed string.

Examples:
    >>> advanced_reverse("hello")
    'olleh'
    >>> advanced_reverse("A man, a plan, a canal, Panama!")
    "!amanaP ,lanac a ,nalp a ,nam A"

Implement `advanced_reverse(s: str) -> str`.
