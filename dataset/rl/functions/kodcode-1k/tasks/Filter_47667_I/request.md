# fibonacci_up_to_n

Write a Jac function to generate the Fibonacci sequence up to a certain number. The function should take an integer `n` as input and return a list of Fibonacci numbers up to but not exceeding `n`.

Example:
- `fibonacci_up_to_n(10) == [0, 1, 1, 2, 3, 5, 8]`

Implement `fibonacci_up_to_n(n: int) -> list[int]`.
