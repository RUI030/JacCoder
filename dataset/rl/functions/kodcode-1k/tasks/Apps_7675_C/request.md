# two_sum

Write a function that takes an integer array nums and an integer target as inputs 
and returns the indices of the two numbers such that they add up to the target. 
You may assume that each input would have exactly one solution, and you may not use 
the same element twice.

>>> two_sum([2, 7, 11, 15], 9) == [0, 1]
>>> two_sum([3, 2, 4], 6) == [1, 2]

Implement `two_sum(nums: list[int], target: int) -> list[int]`.
