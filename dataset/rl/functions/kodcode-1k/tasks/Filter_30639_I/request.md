# circular_shift

Write a code snippet to implement a function that performs a circular shift to the left or right on a given list of integers, depending on the direction specified. The function should take three parameters: a list of integers, a positive integer n representing the number of positions to shift, and a boolean value indicating the direction of the shift (left or right). The function should return the modified list after the shift.

Example:
- `circular_shift([1, 2, 3, 4, 5], 2, True) == [3, 4, 5, 1, 2]`

Implement `circular_shift(lst: list[int], n: int, direction: bool) -> list[int]`.
