# toggle_bulbs

Determines which bulbs are on after performing the sequence of operations.

:param n: integer, number of bulbs
:return: list of integers, 1 if the bulb is on, 0 if it is off

>>> toggle_bulbs(3)
[1, 0, 0]
>>> toggle_bulbs(5)
[1, 0, 0, 1, 0]

Implement `toggle_bulbs(n: int) -> list[int]`.
