# maximum_product_of_three

Returns the maximum product obtained by multiplying any three distinct integers from the list.
If there are fewer than three integers in the list, return 0.

Parameters:
numbers (list): A list of integers.

Returns:
int: The maximum product of three distinct integers from the list.

>>> maximum_product_of_three([]) == 0
>>> maximum_product_of_three([1, 2]) == 0

Implement `maximum_product_of_three(numbers: list[int]) -> int`.
