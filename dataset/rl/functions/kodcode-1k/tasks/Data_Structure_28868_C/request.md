# is_anagram_extended

Determines if t is an anagram of s considering case insensitivity and all printable ASCII characters.

:param s: str
:param t: str
:return: bool

>>> is_anagram_extended("Listen", "Silent") == True
>>> is_anagram_extended("Hello, World!", "dlroW ,!olleH") == True

Implement `is_anagram_extended(s: str, t: str) -> bool`.
