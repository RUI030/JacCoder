# find_n_most_frequent_elements

Create a function that takes an integer array and an integer 'n'. The function should find the 'n' most frequent elements in the array. If there are multiple elements with the same frequency, return the elements in ascending order. Ensure your solution is efficient and uses appropriate data structures.

You can assume that the input array contains only positive integers and 'n' is a positive integer less than or equal to the number of unique elements in the array.

array = [1, 1, 1, 2, 2, 3]
n = 2

Example:
- `find_n_most_frequent_elements([1, 1, 1, 2, 2, 3], 2) == [1, 2]`

Implement `find_n_most_frequent_elements(array: list[int], n: int) -> list[int]`.
