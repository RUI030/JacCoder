# insertion_sort

Sorts a list using the insertion sort algorithm.

Parameters:
arr (list): The list to be sorted.

Returns:
list: The sorted list.

Example:
>>> insertion_sort([3, 1, 4, 2, 5]) 
[1, 2, 3, 4, 5]
>>> insertion_sort([5, 4, 3, 2, 1]) 
[1, 2, 3, 4, 5]

Implement `insertion_sort(arr: list[int]) -> list[int]`.
