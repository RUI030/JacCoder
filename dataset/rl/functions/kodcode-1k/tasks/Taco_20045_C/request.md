# sorted_squares

Given an integer array, return an array that contains the squares of each 
number, sorted in non-decreasing order.

>>> sorted_squares([-4, -1, 0, 3, 10])
[0, 1, 9, 16, 100]
>>> sorted_squares([-7, -3, 2, 3, 11])
[4, 9, 9, 49, 121]

Implement `sorted_squares(arr: list[int]) -> list[int]`.
