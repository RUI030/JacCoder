# repeat_characters

Write a Jac function that takes a string and returns a new string where each character in the original string is repeated once. For instance, the string "hello" should be converted to "hheelllloo". Implement this function without using built-in functions like `str.join()` or `str.replace()`. 

**Example**
- Input : "hello"
- Output : "hheelllloo"
 
- Input : "Coding"
- Output : "CCooddiinngg"

Make sure to handle edge cases such as an empty string or a string with only one character correctly in your implementation.

Example:
- `repeat_characters('hello') == 'hheelllloo'`

Implement `repeat_characters(s: str) -> str`.
