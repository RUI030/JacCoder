# evaluate_expression

Create a function that accepts a string containing a mathematical expression with integers and the operators + and -, and evaluates this expression. The function should be able to handle whitespace within the string and return the final result as an integer. The input string is guaranteed to be a valid expression.

Examples:
- Input: "3 + 4 - 2"
  Output: 5
- Input: "10 + 2 - 6"
  Output: 6
- Input: "100 - 50 + 25"
  Output: 75

Example:
- `evaluate_expression('3 + 4 - 2') == 5`

Implement `evaluate_expression(expression: str) -> int`.
