# min_operations_to_target

Returns the minimum number of operations required to make all elements in nums equal to target.

:param nums: List of integers
:param target: Target integer
:return: Minimum number of operations

>>> min_operations_to_target([5, 5, 5], 5)
0
>>> min_operations_to_target([1, 2, 3], 3)
3

Implement `min_operations_to_target(nums: list[int], target: int) -> int`.
