# reverse_words

Write a function that takes a string as input and returns the string with the order of words reversed. For example, given the input "The quick brown fox", the function should return "fox brown quick The". Assume that all words are separated by spaces and there are no punctuation marks or special characters in the input string.

Example:
- `reverse_words('Hello') == 'Hello'`

Implement `reverse_words(sentence: str) -> str`.
