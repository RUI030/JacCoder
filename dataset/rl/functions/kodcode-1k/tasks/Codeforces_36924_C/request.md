# can_rearrange_to_equal

Determine if it's possible to rearrange both n and m's digits to create two equal numbers.
Returns 'YES' if it's possible, otherwise returns 'NO'.

>>> can_rearrange_to_equal(123, 321) == "YES"
>>> can_rearrange_to_equal(111, 111) == "YES"

Implement `can_rearrange_to_equal(n: int, m: int) -> str`.
