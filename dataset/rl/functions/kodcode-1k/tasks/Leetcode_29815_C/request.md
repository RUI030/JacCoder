# all_unique_in_sliding_window

Return True if all the numbers in the array within each sliding window of length `k` are unique.
>>> all_unique_in_sliding_window([1], 1) == True
>>> all_unique_in_sliding_window([1, 2, 3], 3) == True

Implement `all_unique_in_sliding_window(nums: list[int], k: int) -> bool`.
