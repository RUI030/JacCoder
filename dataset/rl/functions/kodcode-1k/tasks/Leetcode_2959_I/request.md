# sunset_views

You are given a list of integers representing the heights of buildings along a street. Each building `i` is represented by its height `heights[i]`. From the rooftops, you have the opportunity to look at the sunset. A building can see the sunset if it is taller than all the buildings to its right. Write a function that takes in the list `heights` and returns a list of indices of the buildings that can see the sunset, in the order they appear from left to right.

Example:
- `sunset_views([]) == []`

Implement `sunset_views(heights: list[int]) -> list[int]`.
