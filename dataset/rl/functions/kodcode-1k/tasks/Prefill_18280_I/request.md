# swap_a_b

Create a function that takes a string as input and returns a new string where all the 'a's have been replaced with 'b's, and all the 'b's have been replaced with 'a's. The function should be case-sensitive.

Example:
- `swap_a_b('a') == 'b'`

Implement `swap_a_b(input_string: str) -> str`.
