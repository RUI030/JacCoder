# max_equilateral_triangles

Returns the maximum number of equilateral triangles that can be formed
from the given sticks lengths.

>>> max_equilateral_triangles(3, [1, 2, 3]) == 0
>>> max_equilateral_triangles(6, [1, 1, 1, 2, 2, 2]) == 2

Implement `max_equilateral_triangles(n: int, lengths: list[int]) -> int`.
