# find_max_min

Write a Jac function to find the maximum and minimum values in a given list of integers. The function should return a tuple containing the maximum and minimum values respectively. Ensure your function handles an empty list by returning `None`.

Example:
- `find_max_min([1, 2, 3, 4, 5]) == (5, 1)`

Implement `find_max_min(lst: list[int]) -> tuple[int, int] | None`.
