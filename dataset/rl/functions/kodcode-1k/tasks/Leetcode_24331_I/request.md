# primes_less_than

Write a program that takes an integer `n` and returns a list of all prime numbers less than `n`. A prime number is a number that is greater than `1` and has no positive divisors other than `1` and itself. For example, given `n = 10`, the output should be `[2, 3, 5, 7]`.

Example:
- `primes_less_than(10) == [2, 3, 5, 7]`

Implement `primes_less_than(n: int) -> list[int]`.
