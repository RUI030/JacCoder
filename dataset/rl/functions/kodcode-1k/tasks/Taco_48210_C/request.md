# find_top_candidates

Determine the percentage of votes each candidate received and find the candidate(s) with the highest percentage of votes.
>>> find_top_candidates([10, 20, 30])
[2]
>>> find_top_candidates([10, 10, 20, 20])
[2, 3]

Implement `find_top_candidates(votes: list[int]) -> list[int]`.
