# getPrimes

Write a function that takes an integer n and returns a list containing the prime numbers less than n. The numbers in the list should be in ascending order.

Examples:
>>> getPrimes(10)
[2, 3, 5, 7]
>>> getPrimes(20)
[2, 3, 5, 7, 11, 13, 17, 19]

Implement `getPrimes(n: int) -> list[int]`.
