# assemble_sentence

Assembles three given strings into one sentence.

Parameters:
beginning (str): The beginning part of the sentence.
middle (str): The middle part of the sentence.
end (str): The end part of the sentence.

Returns:
str: The complete sentence.

>>> assemble_sentence("I", "like coding", "in Python.")
'I like coding in Python.'
>>> assemble_sentence("Hello", "world", "!")
'Hello world !'

Implement `assemble_sentence(beginning: str, middle: str, end: str) -> str`.
