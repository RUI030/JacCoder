# four_sum

You are given an integer array `arr` and an integer `target`. Your task is to determine if there are four distinct elements in `arr` that sum up to the `target`. If such elements exist, return `true`; otherwise, return `false`. Each input will have exactly one solution, and the same element cannot be used twice.

Example:
- `four_sum([1, 0, -1, 0, -2, 2], 0) == True`

Implement `four_sum(arr: list[int], target: int) -> bool`.
