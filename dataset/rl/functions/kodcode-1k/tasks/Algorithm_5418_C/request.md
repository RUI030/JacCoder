# rotate_matrix

Rotates a given NxN matrix 90 degrees clockwise.
>>> rotate_matrix([
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]) 
[
    [7, 4, 1],
    [8, 5, 2],
    [9, 6, 3]
]
>>> rotate_matrix([
    [1, 2],
    [3, 4]
])
[
    [3, 1],
    [4, 2]
]

Implement `rotate_matrix(matrix: list[list[int]]) -> list[list[int]]`.
