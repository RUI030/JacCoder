# is_palindrome_permutation

Given a `string`, return `true` if the string is a **Palindrome Permutation**. Otherwise, return `false`. A string is a **Palindrome Permutation** if it can be rearranged to form a palindrome. In other words, determine if any permutation of the string could form a valid palindrome.

Example:
- `is_palindrome_permutation('anna') == True`

Implement `is_palindrome_permutation(s: str) -> bool`.
