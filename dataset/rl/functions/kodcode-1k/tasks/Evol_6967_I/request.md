# generate_spiral_matrix

Given an integer n, write a function that generates a spiral matrix of size n x n. The spiral matrix starts with the number 1 and increases sequentially as it fills the matrix in a spiral order, starting in the top-left corner and moving to the right initially.

For example, if n is 3, the output should be:
[[1, 2, 3],
 [8, 9, 4],
 [7, 6, 5]]

Function signature: def generate_spiral_matrix(n: int) -> List[List[int]]

Example:
- `generate_spiral_matrix(1) == [[1]]`

Implement `generate_spiral_matrix(n: int) -> list[list[int]]`.
