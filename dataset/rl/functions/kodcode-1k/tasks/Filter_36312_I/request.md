# sort_and_deduplicate

Create a function that takes in a list of numbers and returns a list of the same numbers, but sorted in a descending order. Additionally, the function should remove any duplicates from the list.

Example:
- `sort_and_deduplicate([3, 1, 2, 3, 4, 1]) == [4, 3, 2, 1]`

Implement `sort_and_deduplicate(numbers: list[int]) -> list[int]`.
