# add_and_multiply

Read the code below and modify it to produce the output for the given input. Not only should your function return the sum, but also multiply it by a specified multiplier which you also receive as input.

Example:
- `add_and_multiply(2, 3, 2) == 10`

Implement `add_and_multiply(a: int, b: int, multiplier: int) -> int`.
