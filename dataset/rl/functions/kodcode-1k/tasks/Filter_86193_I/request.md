# find_unique_characters

You are given a string containing only lowercase letters and spaces. You need to write a Jac function that takes this string as input and returns the characters that appear exactly once in the string, in the order they appear.

Example:
- `find_unique_characters('hello world') == ['h', 'e', ' ', 'w', 'r', 'd']`

Implement `find_unique_characters(s: str) -> list[str]`.
