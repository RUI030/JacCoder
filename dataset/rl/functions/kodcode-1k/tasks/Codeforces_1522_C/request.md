# longest_increasing_subsequence

Given an array of integers, find the length of the longest subsequence in which the elements are in sorted order (strictly increasing).

>>> longest_increasing_subsequence([10, 9, 2, 5, 3, 7, 101, 18])
4
>>> longest_increasing_subsequence([1, 2, 3, 4, 5])
5

Implement `longest_increasing_subsequence(array: list[int]) -> int`.
