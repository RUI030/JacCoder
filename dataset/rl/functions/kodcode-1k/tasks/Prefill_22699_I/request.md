# sum_with_next

Create a function that takes an array of integers and returns an array of the same length where each element is the sum of itself and the next element in the input array. If the input array has only one element, the function returns an array with that single element repeated.

Example:
- `sum_with_next([]) == []`

Implement `sum_with_next(arr: list[int]) -> list[int]`.
