# rotate_matrix_90_degrees

Rotates the given NxN matrix 90 degrees clockwise.

Args:
- matrix (List[List[int]]): The NxN matrix to rotate.

Returns:
- List[List[int]]: The rotated NxN matrix.

Examples:
>>> rotate_matrix_90_degrees([[1, 2], [3, 4]]) 
[[3, 1], [4, 2]]

>>> rotate_matrix_90_degrees([[1, 2, 3], [4, 5, 6], [7, 8, 9]]) 
[[7, 4, 1], [8, 5, 2], [9, 6, 3]]

Implement `rotate_matrix_90_degrees(matrix: list[list[int]]) -> list[list[int]]`.
