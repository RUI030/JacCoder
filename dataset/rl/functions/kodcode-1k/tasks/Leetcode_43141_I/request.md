# count_award_eligible_students

You are given an integer array `heights` representing the heights of a group of students. A student is eligible for an award if they impressively stand out, which is determined by the fact that a student should be taller than both their immediate neighbors. Return _the number of students eligible for an award_.

Example:
- `count_award_eligible_students([]) == 0`

Implement `count_award_eligible_students(heights: list[int]) -> int`.
