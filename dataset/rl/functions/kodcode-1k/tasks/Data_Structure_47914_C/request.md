# cycle_sort

Sort the array in-place using Cycle Sort algorithm and return the sorted array.

Cycle Sort is an in-place and non-stable sorting algorithm that minimizes the number of write operations. 

Args:
arr (List[int]): A list of integers to be sorted.

Returns:
List[int]: The sorted list of integers in ascending order.

Examples:
>>> cycle_sort([8, 3, 2, 5, 9, 1])
[1, 2, 3, 5, 8, 9]
>>> cycle_sort([4, 4, 4, 4])
[4, 4, 4, 4]

Implement `cycle_sort(arr: list[int]) -> list[int]`.
