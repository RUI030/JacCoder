# first_occurrence

Returns the index of the first occurrence of query in array.
If query is not found, returns -1.

>>> first_occurrence([1, 2, 2, 4, 4, 4, 7, 8, 9, 9], 4)
3
>>> first_occurrence([1, 2, 2, 4, 4, 4, 7, 8, 9, 9], 6)
-1

Implement `first_occurrence(array: list[int], query: int) -> int`.
