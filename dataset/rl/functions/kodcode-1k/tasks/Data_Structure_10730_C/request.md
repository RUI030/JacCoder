# cycle_sort

Sorts the array using Cycle Sort algorithm.

This method minimizes the number of writes to the memory.

Args:
    arr (List[int]): A list of integers to be sorted.

Returns:
    List[int]: The sorted list of integers.

Examples:
    >>> cycle_sort([4, 3, 2, 1])
    [1, 2, 3, 4]
    >>> cycle_sort([1, 2, 3, 4])
    [1, 2, 3, 4]

Implement `cycle_sort(arr: list[int]) -> list[int]`.
