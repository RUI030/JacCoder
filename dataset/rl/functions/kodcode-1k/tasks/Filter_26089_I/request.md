# remove_zeros

I have a list in Python, [1,2,0,3,0,4,5], and I want to remove all the zeros from it. How can I implement a function that removes these zeros and returns the modified list?

Example:
- `remove_zeros([1, 2, 0, 3, 0, 4, 5]) == [1, 2, 3, 4, 5]`

Implement `remove_zeros(input_list: list[int]) -> list[int]`.
