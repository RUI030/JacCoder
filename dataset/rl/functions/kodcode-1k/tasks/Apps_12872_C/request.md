# are_anagrams

Determine if str1 can be rearranged to form str2.

Two strings are considered anagrams if they contain the exact same characters with the same frequency but in a different order.

>>> are_anagrams("listen", "silent")
"YES"
>>> are_anagrams("hello", "billion")
"NO"

Implement `are_anagrams(str1: str, str2: str) -> str`.
