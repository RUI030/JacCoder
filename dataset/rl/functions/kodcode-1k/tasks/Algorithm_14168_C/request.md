# is_xor_sequence

Determine if a given list of integers follows an XOR sequence based on a given initial value and a constant XOR value.
>>> is_xor_sequence(1, 2, [1, 3, 1, 3])
True
>>> is_xor_sequence(5, 7, [5, 2, 5, 2])
True

Implement `is_xor_sequence(initial_value: int, xor_value: int, sequence: list[int]) -> bool`.
