# top_student

Returns the name and total score of the student with the highest total score.

>>> top_student([("Alice", 85, 90, 88), ("Bob", 78, 82, 80), ("Charlie", 92, 95, 91)]) ("Charlie", 278)
>>> top_student([("Dave", 70, 75, 80), ("Eva", 85, 89, 90)]) ("Eva", 264)

Implement `top_student(students: list[tuple[str, int, int, int]]) -> tuple[str, int]`.
