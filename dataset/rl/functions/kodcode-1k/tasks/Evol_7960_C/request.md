# product_except_self

Returns a list where each element is the product of all numbers 
in the input list except for the number at that position.

>>> product_except_self([1, 2, 3, 4])
[24, 12, 8, 6]
>>> product_except_self([2, 3, 4, 5])
[60, 40, 30, 24]

Implement `product_except_self(nums: list[int]) -> list[int]`.
