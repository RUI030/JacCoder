# sum_of_list

You are given a task to write a Jac function that takes a list of integers as input and returns the sum of all the integers in the list. Write the function and test it with the list [1, 2, 3, 4, 5].

Example:
- `sum_of_list([1, 2, 3, 4, 5]) == 15`

Implement `sum_of_list(numbers: list[int]) -> int`.
