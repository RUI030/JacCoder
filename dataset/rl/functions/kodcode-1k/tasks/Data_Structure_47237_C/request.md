# cycle_sort

Sorts an array using Cycle Sort algorithm with minimum write operations.
The function takes the list of integers `arr` and returns the sorted list. 
The implementation aims to minimize the number of write operations to the list.

Args:
arr: A list of integers to be sorted.

Returns:
The sorted list of integers.

Examples:
>>> cycle_sort([4, 3, 2, 1, 5])
[1, 2, 3, 4, 5]
>>> cycle_sort([4, 3, 3, 4, 1])
[1, 3, 3, 4, 4]

Implement `cycle_sort(arr: list[int]) -> list[int]`.
