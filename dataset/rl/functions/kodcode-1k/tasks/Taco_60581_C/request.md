# reverseEveryOther

Reverses every other word in the given sentence.

:param sentence: A string of words separated by spaces.
:return: A modified sentence with every other word reversed.

>>> reverseEveryOther("Hello world this is a test")
"Hello dlrow this si a tset"
>>> reverseEveryOther("Coding is fun")
"Coding si fun"

Implement `reverseEveryOther(sentence: str) -> str`.
