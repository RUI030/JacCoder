# find_lis_length

Compute the length of the longest increasing subsequence (LIS) in an unsorted array of unique integers.
The function aims to handle input sequences quickly with a time complexity of O(n log n).
>>> find_lis_length([10, 9, 2, 5, 3, 7, 101, 18])  # Output: 4
>>> find_lis_length([0, 8, 4, 12, 2, 10, 6, 14, 1, 9, 5, 13, 3, 11, 7, 15])  # Output: 6

Implement `find_lis_length(sequence: list[int]) -> int`.
