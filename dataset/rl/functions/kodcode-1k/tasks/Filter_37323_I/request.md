# odd_prime_digits_info

Develop a Jac function that not only determines if a number contains odd digits, but also identifies if these digits are prime. The function should return a tuple where the first value indicates if there are odd digits, the second denotes if these odd digits are prime, and the third reveals the total count of these odd prime digits.

Example:
- `odd_prime_digits_info(2468) == (False, False, 0)`

Implement `odd_prime_digits_info(number: int) -> tuple[bool, bool, int]`.
