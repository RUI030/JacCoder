# max_consecutive_sum

Returns the maximum sum of k consecutive elements in the list nums.
If k is larger than the list length or any other edge case, return 0.

>>> max_consecutive_sum([1, 2, 3, 4, 5], 2) == 9
>>> max_consecutive_sum([5, 4, 3, 2, 1], 3) == 12

Implement `max_consecutive_sum(nums: list[int], k: int) -> int`.
