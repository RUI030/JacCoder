# can_convert_by_rearranging

Determine if you can convert string `s` into string `t` by performing 
some number of operations, where in one operation you can select any 
substring of `s` and rearrange its characters in any order.

>>> can_convert_by_rearranging("abc", "bca")
True
>>> can_convert_by_rearranging("abc", "abcd")
False

Implement `can_convert_by_rearranging(s: str, t: str) -> bool`.
