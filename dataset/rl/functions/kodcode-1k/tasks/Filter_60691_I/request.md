# fibonacci_sequence

Write a Jac code to find the Fibonacci sequence up to the nth term. The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones, usually starting with 0 and 1. For example, if n = 7, the sequence should be: 0, 1, 1, 2, 3, 5, 8.

Example:
- `fibonacci_sequence(0) == []`

Implement `fibonacci_sequence(n: int) -> list[int]`.
