# is_valid_expression

Check if the given string is a valid expression following simplified Python 3.10 grammar.

Args:
expression (str): The expression to be validated.

Returns:
bool: True if the expression is valid, False otherwise.

>>> is_valid_expression("123 + 456")
True
>>> is_valid_expression("(1 + 2) * 3.5")
True

Implement `is_valid_expression(expression: str) -> bool`.
