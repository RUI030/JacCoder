# sort_odd_numbers

Write a function that takes an array of integers and returns the same array sorted in ascending order, but only the odd numbers should be sorted, while the even numbers remain in their original positions. For example, running this function on the array [4, 3, 2, 1, 5] would produce [4, 1, 2, 3, 5].

Example:
- `sort_odd_numbers([4, 2, 6, 8]) == [4, 2, 6, 8]`

Implement `sort_odd_numbers(arr: list[int]) -> list[int]`.
