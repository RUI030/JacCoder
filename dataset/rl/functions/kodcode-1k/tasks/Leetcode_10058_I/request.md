# can_attend_meetings

Given a list of meeting time intervals consisting of start and end times `[[s1, e1], [s2, e2], ...]` (si < ei), determine if a person could attend all meetings. The list is not necessarily ordered. Return `true` if a person can attend all meetings without conflicts, otherwise return `false`.

Example:
- `can_attend_meetings([]) == True`

Implement `can_attend_meetings(intervals: list[list[int]]) -> bool`.
