# rectangle_dimensions

Create a function that will take the area of a rectangle and a basic algorithm that will find the possible dimensions that a rectangle could have with a given area. For example, if given the area 24, the function should output the dimensions (length, width) that could represent that same area. We'll assume all rectangle dimensions are integers.

Example:
- `rectangle_dimensions(24) == [(1, 24), (2, 12), (3, 8), (4, 6)]`

Implement `rectangle_dimensions(area: int) -> list[tuple[int, int]]`.
