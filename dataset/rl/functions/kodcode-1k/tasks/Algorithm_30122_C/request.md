# circular_array_rotation

Rotates the array to the right by k steps.

:param arr: List of integers to be rotated.
:param k: Number of right rotations.
:return: The array after k right rotations.

>>> circular_array_rotation([1, 2, 3, 4, 5], 2)
[4, 5, 1, 2, 3]
>>> circular_array_rotation([1, 2, 3, 4, 5], 5)
[1, 2, 3, 4, 5]

Implement `circular_array_rotation(arr: list[int], k: int) -> list[int]`.
