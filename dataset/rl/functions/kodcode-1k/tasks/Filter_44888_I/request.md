# second_largest

Write a Jac program to find the second largest number in a list. The list can contain both positive and negative integers. The program should handle duplicates and return the correct second largest number. If the list does not contain at least two distinct numbers, the program should return `None`.

Example:
- `second_largest([1, 3, 4, 5, 0, 2]) == 4`

Implement `second_largest(numbers: list[int]) -> int | None`.
