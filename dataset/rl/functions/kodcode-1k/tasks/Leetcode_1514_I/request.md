# shuffle_string

Given a string `s` and an integer array `indices` of the same length, where `indices[i]` represents the position to which the character `s[i]` should be moved, return _the shuffled string_.

Example:
- `shuffle_string('abc', [0, 1, 2]) == 'abc'`

Implement `shuffle_string(s: str, indices: list[int]) -> str`.
