# longestIncreasingSequence

Write a function that takes an integer array as input and returns the longest sequence of increasing numbers.
If there are multiple sequences with the same length, return the first one encountered.

>>> longestIncreasingSequence([1, 2, 1, 2, 3, 4, 1]) == [1, 2, 3, 4]
>>> longestIncreasingSequence([5, 1, 2, 3, 4, 5, 4, 3, 2, 1]) == [1, 2, 3, 4, 5]

Implement `longestIncreasingSequence(nums: list[int]) -> list[int]`.
