# concatenate_strings

Create a function in Python that takes a list of strings and returns a single string which is the concatenation of all elements in the list, separated by spaces. If the list is empty, the function should return an empty string. Use only basic Jac functionality, no external libraries.

Example:
- `concatenate_strings([]) == ''`

Implement `concatenate_strings(string_list: list[str]) -> str`.
