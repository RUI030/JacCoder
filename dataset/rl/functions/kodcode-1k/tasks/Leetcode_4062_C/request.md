# max_diff_in_contiguous_subarray

Given an integer array nums, return the maximum difference between the largest and smallest values in any contiguous subarray of nums. If the array contains fewer than 2 elements, return 0.
>>> max_diff_in_contiguous_subarray([]) == 0
>>> max_diff_in_contiguous_subarray([5]) == 0

Implement `max_diff_in_contiguous_subarray(nums: list[int]) -> int`.
