# second_largest

Write a function in Python that takes a list of integers and returns the second largest number in the list. If the list does not contain at least two distinct numbers, the function should return `None`. Ensure your function handles edge cases such as an empty list or a list with all elements being the same.

Example:
- `second_largest([1, 2, 3, 4, 5]) == 4`

Implement `second_largest(numbers: list[int]) -> int | None`.
