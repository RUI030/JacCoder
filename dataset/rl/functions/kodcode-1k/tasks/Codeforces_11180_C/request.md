# max_sum_with_one_removal

Find the maximum possible sum of a contiguous subarray of the given array,
allowing the removal of at most one element.
>>> max_sum_with_one_removal([1, -2, 0, 3, -1])
4
>>> max_sum_with_one_removal([-1, -1, -1])
-1

Implement `max_sum_with_one_removal(arr: list[int]) -> int`.
