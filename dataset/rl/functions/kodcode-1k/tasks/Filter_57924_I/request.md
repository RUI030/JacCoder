# is_leap_year

I need to evaluate a Jac function that checks if a given year is a leap year. The function should return `True` for leap years and `False` for non-leap years. A leap year is exactly divisible by 4 except for century years (years ending with 00). The century year is a leap year only if it is perfectly divisible by 400. Can you provide a test case to verify the correctness of this function?

Example:
- `is_leap_year(2024) == True`

Implement `is_leap_year(year: int) -> bool`.
