# substrings_in_reverse_order

Create a function that takes a string as input and returns a list of all possible substrings 
of the input string. The function should return the substrings in reverse order of their length, 
starting with the longest substring and ending with the shortest substring.

>>> substrings_in_reverse_order('a')
['a']

>>> substrings_in_reverse_order('ab')
['ab', 'a', 'b']

Implement `substrings_in_reverse_order(input_string: str) -> list[str]`.
