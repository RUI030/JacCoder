# longest_alternating_string

You are given a string `s` consisting of only characters `a` and `b`. You can delete any number of characters from `s` to create a new string. The goal is to form the string with the longest length possible such that it contains alternating characters `a` and `b` and starts with the character `a`. Return the longest alternating string you can form.

Example:
- `longest_alternating_string('aaaa') == 'a'`

Implement `longest_alternating_string(s: str) -> str`.
