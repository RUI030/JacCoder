# count_non_overlapping_occurrences

Create a function that takes two parameters, a string and a substring, and returns the count of non-overlapping occurrences of the substring in the string.

Example:
- `count_non_overlapping_occurrences('hello world', 'test') == 0`

Implement `count_non_overlapping_occurrences(main_string: str, sub_string: str) -> int`.
