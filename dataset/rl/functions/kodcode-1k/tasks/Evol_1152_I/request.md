# are_anagrams

Optimize the routine to detect if a given string is an anagram of another string. Consider strings "listen" and "silent" as examples. The function should be case-sensitive and take into account all characters, including spaces and punctuation marks. Provide a brief explanation of how your solution addresses the problem efficiently.

Example:
- `are_anagrams('listen', 'listen') == True`

Implement `are_anagrams(s1: str, s2: str) -> bool`.
