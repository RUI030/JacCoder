# filter_even_numbers

Implement a function that takes a list as an argument and returns a new list with the even numbers from the original list. If the input is None, the function should return None.

Example:
- `filter_even_numbers([1, 2, 3, 4, 5, 6]) == [2, 4, 6]`

Implement `filter_even_numbers(lst: list[int] | None) -> list[int] | None`.
