# count_common_volunteers

Returns the count of volunteers who are involved in both the reforestation and water cleaning projects.
>>> count_common_volunteers(3, [1, 2, 3], 3, [4, 5, 6])
0
>>> count_common_volunteers(4, [1, 2, 3, 4], 4, [3, 4, 5, 6])
2

Implement `count_common_volunteers(n: int, reforestation_volunteers: list[int], b: int, water_cleaning_volunteers: list[int]) -> int`.
