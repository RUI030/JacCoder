# max_sum_of_non_overlapping_positive_subarrays

Determine the maximum sum that can be obtained by choosing non-overlapping subarrays such that the sum of each chosen subarray is positive.
>>> max_sum_of_non_overlapping_positive_subarrays([1, -2, 3, 4, -5]) 8
>>> max_sum_of_non_overlapping_positive_subarrays([-1, -2, -3, -4, -5]) 0

Implement `max_sum_of_non_overlapping_positive_subarrays(arr: list[int]) -> int`.
