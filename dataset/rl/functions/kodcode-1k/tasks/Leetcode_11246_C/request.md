# can_transform

Determines if str1 can be transformed into str2 by any number of swaps.

Parameters:
- str1: The first string.
- str2: The second string.

Returns:
- A boolean indicating whether str1 can be transformed into str2.

Examples:
>>> can_transform("abc", "abc")
True
>>> can_transform("abc", "cba")
True

Implement `can_transform(str1: str, str2: str) -> bool`.
