# factorial

Write a function to calculate the factorial of a number `(n!)`. Implement it in Python. Every student will receive a reward for their outstanding academic performance based on `n` points. How many ways can these rewards be distributed to the students if each student receives at least one point, and no two students receive the same number of points?

Example:
- `factorial(0) == 1`

Implement `factorial(n: int) -> int`.
