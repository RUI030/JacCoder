# min_absolute_sum_difference

Returns the minimum sum of absolute differences between array1 and array2 
after performing the allowed swap operations.
>>> min_absolute_sum_difference([1, 2, 3], [1, 2, 3]) == 0
>>> min_absolute_sum_difference([1, 3, 5], [4, 2, 6]) == 3

Implement `min_absolute_sum_difference(array1: list[int], array2: list[int]) -> int`.
