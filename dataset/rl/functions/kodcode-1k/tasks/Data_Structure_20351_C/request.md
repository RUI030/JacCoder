# shell_sort

Sort an array using the Shell Sort algorithm.
The function sorts the array in-place and returns the sorted array.
>>> shell_sort([12, 34, 54, 2, 3])
[2, 3, 12, 34, 54]
>>> shell_sort([64, 34, 25, 12, 22, 11, 90])
[11, 12, 22, 25, 34, 64, 90]

Implement `shell_sort(arr: list[int]) -> list[int]`.
