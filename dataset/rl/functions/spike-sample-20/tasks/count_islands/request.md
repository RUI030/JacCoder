# Count islands in a grid

Implement `count_islands(grid: list[str]) -> int`. Each string is one row of the
grid; `#` is land and `.` is water. An island is a group of land cells connected
horizontally or vertically (not diagonally). Return the number of islands. Rows
all have the same length; the grid may be empty.

Example:
- `count_islands(["##..", "#..#", "...#"]) == 2`
