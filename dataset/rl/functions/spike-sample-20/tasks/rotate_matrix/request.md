# Rotate a matrix clockwise

Implement `rotate_matrix(m: list[list[int]]) -> list[list[int]]`. Return a new
matrix that is `m` rotated 90 degrees clockwise. `m` may be rectangular (not only
square) and may be empty. Do not modify the input.

Example:
- `rotate_matrix([[1, 2], [3, 4]]) == [[3, 1], [4, 2]]`
